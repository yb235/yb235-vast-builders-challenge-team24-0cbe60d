# VAST Builders Challenge

Starter repo for the VAST Builders Challenge. A video pipeline is already running: it
ingests footage, describes what's in it, and indexes it for search. 

You build on top, from Cursor: search the archive in plain language, ask questions about it, or wire it
into an agent or app that takes action:

- **Before the day:** [BEFORE_YOU_BUILD.md](BEFORE_YOU_BUILD.md), what to do in advance. ([PDF](docs/BEFORE_YOU_BUILD.pdf))
- **Start here:** [BUILD_DAY.md](BUILD_DAY.md), the guide for the day. ([PDF](docs/BUILD_DAY.pdf))
- **Deeper dive:** [ARCHITECTURE_REFERENCE.md](ARCHITECTURE_REFERENCE.md), the full video
  corpus, metadata reference, example queries, and demo packs. ([PDF](docs/ARCHITECTURE_REFERENCE.pdf))

PDF versions are there in case GitHub is down.
